# GoHighLevel Build Blueprint - [Business / Industry]
*Draft for review - nothing below has been built yet.*

## 0. Snapshot
- **Business:** what they sell, to whom, average ticket, sales cycle
- **Primary goal of this build:** one sentence, one metric
- **Assumptions:** every default taken because intake was not answered
- **Prerequisites:** payment provider, LC Phone + A2P 10DLC, verified sending domain,
  AI credits, Meta/Google access, domain and DNS control - with owner and blocker status
- **Out of scope / platform limits:** what GHL will not do here and the bridge used instead

## 1. Calendars
Table of calendars: name / type / duration / assigned / notice + range / deposit / booked-stage.
Then per calendar: full settings, reminder cadence, no-show handling. End with **Wires into:**.

## 2. Contact Smart Lists
Foundations first: custom fields, tag taxonomy, contact-type rule.
Then a table of smart lists: name / filter logic / who works it / cadence / action taken.
End with **Wires into:**.

## 3. Opportunities & Pipeline Stages
One block per pipeline: purpose, stage table (stage / entry event / exit event / automation /
lead value), status rules, stale threshold, owner assignment. End with **Wires into:**.

## 4. Payments
Products and prices, invoice and estimate usage, deposits, contracts, subscriptions and dunning,
coupons, and the exact revenue events that fire automation. End with **Wires into:**.

## 5. AI Agents
Per agent: role, channel, hours, the four prompt parts, training sources, enabled actions,
handover rules, and a **Guardrails** block of hard refusals. Include expected usage cost.
End with **Wires into:**.

## 6. Marketing
Email programme, SMS programme with compliance rules, social cadence, ads and offline conversion
events, trigger links, review engine. End with **Wires into:**.

## 7. Automation & Workflows
Numbered folders, then one row per workflow: number / name / trigger / key actions / exit goal.
Expand the five most important workflows step by step, with real message copy.
End with **Wires into:**.

## 8. Funnels
Per funnel: offer, steps, page-by-page content, form fields and consent copy, tags and
opportunity created, split tests. End with **Wires into:**.

## 9. Websites
Sitemap, page-by-page purpose and primary CTA, SEO targets, tracking, chat widget, and the
existing-site decision. End with **Wires into:**.

## 10. Build Order
Phased: what must exist before what, with a rough day count per phase.

## 11. Pre-Launch QA Checklist
Real test steps with a pass condition each - book a test appointment, force a no-show, pay a $1
invoice, trigger the AI with an emergency phrase, send a test SMS from a real handset.

## 12. Reporting
Which dashboards and numbers get reviewed weekly, and the definition of each metric.
